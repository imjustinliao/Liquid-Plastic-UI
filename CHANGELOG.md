# Changelog

All notable changes to Liquid Plastic UI are documented here.

## 0.0.0 — 2026-09-27

- Added `SegmentedControl`, `LiquidButton`, and `LiquidSwitch`.
- Added controlled and uncontrolled React APIs with TypeScript declarations.
- Added front-facing liquid-plastic materials, pointer reflection, press ripple, and accessibility fallbacks.
- Added an interactive Vite playground, unit/browser tests, package validation, and documentation screenshots.
